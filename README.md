# my_claude_skills

직접 만든 Claude 스킬, 플러그인, 커넥터를 모아 관리하는 저장소입니다.
각 프로젝트는 브랜치 하나에 따로 둡니다.

| 브랜치 | 내용 | 설치 |
|---|---|---|
| `ai_discussion` | `ai-discussion` 플러그인 마켓플레이스. Claude와 Codex가 한 주제를 함께 토의하게 하는 `/ai-discussion:start` 스킬 | `/plugin marketplace add rmia4/my_claude_skills#ai_discussion` 후 `/plugin install ai-discussion@my-claude-skills` |
